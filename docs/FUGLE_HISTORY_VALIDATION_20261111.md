只更新 `release/v1.0-development`。候選站的 Source 按鈕已在 2026-11-11 現場確認連到該分支的 `app.py`。不修改 main、b3-speed-test、production 分支或提醒／交易流程，不合併分支。

候選站首頁有「富果歷史日K驗證（受保護測試頁）」按鈕；亦可開啟：
https://adam-v1-candidate.streamlit.app/?view=fugle-history

`PRODUCTION_MODE` 為 true 時，不顯示入口，也不執行此路由。新頁在開發模式獨立停止，不進入選股或提醒面板。

## 使用與秘密保護

1. 直接在候選站頁面輸入既有個人報價密碼。不要把密碼或 API 金鑰傳入聊天、檔案或 GitHub。
2. 按「執行三檔一年驗證（最多6次查詢）」。每次明確執行最多6個循序唯讀請求，三檔各分兩段；每段小於一年。第一次錯誤即停止，不重試或換來源。
3. 查看各檔的價格、日期、缺值與成交量差異，下載不含秘密的 JSON 報告。返回首頁或鎖定會清除這個頁面的結果與密碼。

頁面沿用伺服器的 `FUGLE_API_KEY` 和 `LIVE_QUOTE_PASSWORD`，不顯示、複製或搬運。金鑰只在 HTTPS 標頭傳給既定富果 API，拒絕重新導向。錯誤只顯示固定訊息及 HTTP 狀態，不輸出原始錯誤或回應。結果只存在當次 session，不用共用快取、不寫磁碟或 GitHub。60秒重複查詢限制是每 session，不是帳號全域限制；請勿多開頁籤同時查詢。

## 比對方法

- 固定股票：5474 聰泰、6708 天擎、9962 有益。樣本非隨機，不能外推全市場。
- 固定期間：2025-11-11 至 2026-11-11，含兩端。兩個分段各183個曆日，不重疊、不缺日。
- 富果：`timeframe=D`、`adjusted=false`、升冪日期；核對股票、交易所、週期、日期範圍、重複列與資料型別。未回傳 `adjusted` 時記錄為 omitted，保留「明確請求未還原」與已回傳旗標的區別。
- TPEx：使用先前公開月表實測的凍結 CSV，見 `docs/evidence/tpex-fugle-baseline-20261111/`。各CSV有SHA256、13個月份的請求來源及回應校驗證據，本頁不重新呼叫TPEx。
- 同日有效OHLC逐欄比較，絕對容差0.005元；同時報告未比對的缺值與日期，不能只以零價差宣稱完整通過。
- 2026-10-23休市、6708七天官方無OHLC均單獨列示。不自動補零、補平盤、移除日期或混用不同基準。
- 富果日K量為股，含鉅額；TPEx月表量為張且不含鉅額。張×1000不恢復逐股精度。報告量差不等同資料錯誤，未取得逐日鉅額明細前也不將差異全部歸因鉅額。
- 富果文件指出日K通常於16:30前更新，當日鉅額約18:00後併入，也可能延後。報告保留實際查詢時間。

文件來源：https://developer.fugle.tw/docs/data/http-api/historical/candles/
