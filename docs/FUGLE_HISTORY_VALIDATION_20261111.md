# 候選站富果一年歷史日K驗證（FUGLE-HISTORY-20261111-2）

## 擴大測試

原三檔按鈕保留，最多6次。新增獨立按鈕測試10檔一年日K及名單，最多22次（20次歷史＋2次名單）。兩個按鈕共用60秒session冷卻；沒有自動查詢、背景重查或共用付費快取。兩段各183日，固定2025-11-11至2026-11-11。擴大樣本固定為5276、4153、1240、4121、8927、6419、8436、3303、3236、1815；按官方當日成交量分層選取，非隨機，也不代表未抽到的股票已通過。

官方母體為2026-11-11 TPEx「上櫃股票基本資料」的897個發行公司代碼，與當日報價精確代碼比對；不是13,752列全證券報價數，也不是完整逐種類證券分類驗證。所有新掛牌、缺一般交易收盤價及已證實停牌者留在名單母體。官方一般交易收盤價缺漏不等於完全無成交：23檔有報價列但無有效收盤價，另4534、4804無報價列且官方停止交易欄位為Ｙ。45檔在測試期間新掛牌，另列標示。歷史抽樣排除新掛牌、缺收盤價和零量，只限制樣本，不縮減母體。

富果名單用 `/intraday/tickers?type=EQUITY&exchange=TPEx&market=OTC`，另一次同條件加 `isHalted=true` 補查。絕不加入 `isNormal=true`；文件的EQUITY也可能包含非普通股，故不把原始數量當普通股數。兩份名單內不得重複代碼，跨查詢可重疊並取聯集。產業00只作未分類觀察，不作證券種類的充分證明。額外代碼全列出並標記未分類，不自動改變官方母體。

官方文件沒有可指定歷史日期的名單參數。必須記錄兩次回傳日期，兩次不一致停止；同為另一日期則保留觀察交集、明示日期不符並把當日涵蓋率設為null，仍繼續歷史測試。即使日期相同，也只是同日期回應觀察，不宣稱歷史時點名單等價。名單涵蓋率與日K有效日期完整率完全分開。

新凍結證據放在 `docs/evidence/tpex-fugle-expanded-20261111/`。執行前檢查完整狀態、897筆母體、日期、分類、樣本成員及SHA256，並預載全部10檔CSV以避免基準不完整時耗用付費額度。官方沒有OHLC的實際資料列保留空值和已報成交量，不能補造價格。有效OHLC完整率只使用官方有效日期，但另列所有官方無OHLC日期。每次HTTP嘗試（含失敗）記錄固定目標、計數與狀態，無錯誤本文或憑證；日K回應最多2MB、名單最多4MB、20秒timeout、拒絕redirect、間隔1.1秒且不重試。

## 使用與秘密保護

1. 直接在候選站頁面輸入既有個人報價密碼。不要把密碼或 API 金鑰傳入聊天、檔案或 GitHub。
2. 按「執行三檔一年驗證（最多6次查詢）」。每次明確執行最多6個循序唯讀請求，三檔各分兩段；每段小於一年。第一次錯誤即停止，不重試或換來源。
3. 查看各檔的價格、日期、缺值與成交量差異，下載不含秘密的 JSON 報告。返回首頁或鎖定會清除這個頁面的結果與密碼。

頁面沿用伺服器的 `FUGLE_API_KEY` 和 `LIVE_QUOTE_PASSWORD`，不顯示、複製或搬運。金鑰只在 HTTPS 標頭傳給既定富果 API，拒絕重新導向。錯誤只顯示固定訊息及 HTTP 狀態，不輸出原始錯誤或回應。結果只存在當次 session，不用共用快取、不寫磁碟或 GitHub。60秒重複查詢限制是每 session，不是帳號全域限制；請勿多開頁籤同時查詢。

## 比對方法

- 固定股票：5474 聰泰、6708 天擎、9962 有益。樣本非隨機，不能外推全市場。
- 固定期間：2025-11-11 至 2026-11-11，含兩端。兩個分段各183個曆日，不重疊、不缺日。
- 富果：`timeframe=D`、`adjusted=false`、升冪日期；核對股票、交易所、週期、日期範圍、重複列與資料型別。未回傳 `adjusted` 時記錄為 omitted，保留「明確請求未還原」與已回傳旗標的區別。
- TPEx：使用先前公開月表實測的凍結 CSV，見 `docs/evidence/tpex-fugle-baseline-20261111/`。各CSV有SHA256、13個月份的請求來源及回應校驗證據，本頁不重新呼叫TPEx。
- 同日有效OHLC逐欄比較，絕對容差0.005元；同時報告未比對的缺值與日期，不能只以零價差宣稱完整通過。
- 2026-10-23休市、6708七天官方無OHLC均單獨列示。不自動補零、補平盤、移除日期或混用不同基準。
- 富果日K量為股，含鉅額；TPEx月表量為張且不含鉅額。張×1000不恢復逐股精度。報告量差不等同資料錯誤，未取得逐日鉅額明細前也不將差異全部歸因鉅額。
- 富果文件指出日K通常於16:30前更新，當日鉅額約18:00後併入，也可能延後。報告保留實際查詢時間。
